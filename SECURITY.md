# Security Policy

## Reporting a vulnerability

If you find a security issue in these scripts, or in anything they verify on-chain, please report it privately first:

- Email: solfoundryio@gmail.com
- Or use GitHub's private vulnerability reporting on this repository ("Report a vulnerability" under the Security tab).

Please do not open a public issue for security reports. We aim to respond within 72 hours.

## Scope

This repository contains read-only inspection scripts. They never sign or send transactions and never handle private keys. Reports about the SolFoundry launchpad itself (solfoundry.io) are also welcome through the same channels.

## Supported versions

Only the latest commit on `main` is supported. There are no maintained release branches.
